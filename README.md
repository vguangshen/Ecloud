# 移动云电脑保活

在云电脑内部定时打开移动云客户端，通过客户端自动连接自身，尝试刷新平台的未连接计时。客户端需要提前登录，并具备自动连接对应云电脑的行为。

## 长期运行

- Windows 登录计划任务设置为无限运行，取消默认的 72 小时停止上限；异常退出后由计划任务最多重启 3 次，每次间隔 1 分钟。
- 开始保活或随 Windows 登录启动时，立即尝试启动客户端。
- 新配置默认每 360 分钟（6 小时）启动一次，最大 720 分钟（12 小时）。旧配置超过上限时会降至 720 分钟，给 24 小时未连接关机策略留出余量。
- 启动客户端报错后每 5 分钟重试；运行期间修改间隔以及点击“立即保活”都会更新实际执行时间。
- 自动结束客户端的新默认延迟为 120 秒；已有延迟设置保留，请根据实际连接耗时调整。

“启动客户端成功”不等于“云连接成功”。本工具没有读取云平台的实际连接结果，也没有自动处理登录失效或验证码。部署时应确认客户端能在结束延迟内连接自身，再观察平台记录是否刷新。

## 更新旧版本

1. 从托盘退出旧工具，将新程序放到长期使用的固定路径，再打开新程序。
2. 在“启动项”页点击“立即注册到 Windows 计划任务中”，授权后覆盖旧任务。只替换 EXE 不会移除旧任务里的运行时限。
3. 在“状态”页确认计划任务显示“运行不限时”。运行间隔建议设为 360 分钟，然后点击“开始保活”。

任务名为 `EcloudKeepAlive.UnattendedStartup`。可以在 PowerShell 只读核对：

```powershell
(Get-ScheduledTask -TaskName 'EcloudKeepAlive.UnattendedStartup').Settings.ExecutionTimeLimit
```

应为 `PT0S`（或等价的零时长）。此任务在用户登录 Windows 时启动，需要保留交互式登录会话；它不提供关机后自动开机、无人登录启动或平台强制回收后的恢复能力。

## 排查

运行日志位于 `%APPDATA%\EcloudKeepAlive\runtime.log`，超过 1 MiB 时保留一份 `.previous`。日志记录启动尝试、失败重试、客户端结束以及配置读写异常，不记录密码。

FRPC 仍是启动工具时按选项拉起一次，并非持续进程守护。如果远程连接断开，应同时检查 FRPC 进程、Windows 事件日志和云平台电源状态，区分断网、工具退出及真正关机。

## 验证

```powershell
dotnet run --project tests/RegressionTests.csproj -c Release
dotnet publish EcloudKeepAlive.csproj -c Release -r win-x64 --self-contained true
```

回归测试使用生产调度逻辑推进 100 天，并模拟连续 48 小时的启动失败、恢复、手动执行和修改间隔。Windows 上另外通过实际 Task Scheduler COM 对象检查无限时长、失败重启和序列化后的任务 XML，不注册或运行测试计划任务。时间推进测试不等于真实云环境中的连续驻留验证。
